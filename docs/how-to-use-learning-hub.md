# Japanese Learning Hub — How to Use It

_Last updated: 18 September 2026_

This guide describes the current day-to-day workflow for the Japanese Learning Hub. It is intended as a user guide, not a developer or architecture document.

---

## 1. What the Learning Hub is for

The Learning Hub is a private study dashboard for organising your Japanese study around:

- a structured study programme
- textbooks and lessons
- guided lesson sessions
- grammar references
- personal sentence capture
- audio and shadowing practice
- supplementary grammar practice
- progress tracking
- Pomodoro-based study sessions

The intended study flow is:

**Home → Plan → Book / Lesson → Guided Lesson**

The Hub and Repository support that workflow rather than replacing it.

A useful rule is:

> If you are unsure what to do next, go to **Plan** and continue the next scheduled lesson.

---

## 2. Main navigation

### Home

Home is the quick overview page.

Use it to:

- see your current programme
- resume recent study
- check current progress
- jump back into your active lesson

Home is not intended to contain every feature. It is the starting point.

### Plan

Plan is the main study schedule.

Use it to:

- see the current week
- see scheduled tasks
- open the lesson you should be working on
- track progress through the programme
- move through the 12-week study plan

The plan currently focuses on the Tobira pathway.

For the current Beginning II programme:

- Weeks 1–10 work through Lessons 11–20
- Weeks 11–12 are for consolidation

The plan start date is available in the compact footer at the bottom of the Plan page.

Changing the start date changes how the plan aligns to calendar dates.

### Lessons

Lessons are organised by book and lesson.

The normal path is:

**Book → Lesson → Guided Lesson**

A lesson can contain several study stages, including:

1. Read textbook pages
2. Watch lesson videos
3. Complete workbook pages
4. Audio practice
5. Conversation / shadowing practice
6. Listening, speaking and reading activities

Use the lesson page to understand what belongs to the lesson.

Use **Guided Lesson** when you are ready to actually study it.

### Hub

Hub is the resource and programme management area.

It contains:

- Current Programme
- Planned Programmes
- Book Library
- Study Tools

These sections can be collapsed when not needed.

#### Current Programme

Shows the programme currently driving the Plan.

Only one programme should be active at a time.

#### Planned Programmes

Contains programmes you may study later.

Planning a programme does not automatically make it active.

#### Book Library

Contains study resources and mapped textbooks.

A book can exist in the library without being part of the active study programme.

#### Study Tools

Provides access to supporting study resources and tools.

The Hub should be used for resource management, not as the main place to decide what to study each day.

For daily study, use **Plan**.

---

## 3. Guided Lesson

Guided Lesson is the main focused-study workspace.

Use it when working through an actual textbook lesson.

It is designed to keep the lesson workflow in one place instead of requiring constant navigation between pages.

Typical study sequence:

1. Open the lesson from Plan
2. Start Guided Lesson
3. Work through the current task
4. Use the built-in Pomodoro if useful
5. Complete the task
6. Continue to the next step
7. Add notes where relevant
8. Finish the lesson when all required work is complete

The lesson workspace remembers useful session state so you can move between steps without losing your place.

---

## 4. Pomodoro

The Pomodoro timer is integrated into study sessions.

Use it when you want focused blocks of study time.

The timer is shared globally, so navigating within the Hub should not create a separate competing timer.

When using it inside Guided Lesson, it is associated with the study workflow rather than being a standalone productivity tool.

A practical default is:

- 25 minutes study
- short break
- resume the same lesson task

Do not worry about using Pomodoro for every study session. It is optional.

---

## 5. Audio and shadowing

Audio is available within lesson activities where source material has been mapped.

Audio practice can include:

- 会話
- 単語リスト
- 話しましょう
- 聞きましょう
- 読みましょう
- conversation shadowing

The audio panel is designed to remain available while working through related lesson material.

For shadowing:

1. Listen once without speaking
2. Listen again while following the text
3. Repeat with the speaker
4. Repeat again while trying to match timing and rhythm
5. Only then worry about individual pronunciation problems

The goal is not perfect imitation on the first attempt.

---

## 6. Japanese Repository

The Repository is for personal Japanese material that you want to keep and study later.

Typical entries include:

- example sentences
- corrected sentences
- useful phrases
- vocabulary in context
- personal Japanese notes

The Repository is separate from the textbook lesson structure.

Use it for Japanese you encounter or create that is worth keeping.

Do not duplicate an entire textbook lesson into the Repository.

---

## 7. Sentence capture

When you want to save a useful Japanese sentence, the sentence can be imported into the Repository.

A sentence can include:

- Japanese
- furigana
- English meaning
- short explanation
- grammar annotations
- register
- tags
- source information
- notes

Grammar annotations should link to existing canonical grammar concepts.

The sentence itself keeps the wording actually used.

---

## 8. Canonical Grammar Library

The Grammar Library stores grammar **concepts**, not every surface form.

Examples:

- 見てたら links to **〜たら** and **〜ている**
- 食べちゃった links to **〜てしまう**
- 何してる links to **〜ている**

Surface forms belong to sentence context or variation data.

They should not become separate grammar guides just because they look different.

This keeps the grammar library clean and prevents duplicate grammar entries.

---

## 9. Opening grammar from a sentence

When a saved sentence has grammar annotations, use those links to open the canonical grammar guide.

A grammar guide can contain:

- meaning
- formation
- usage
- nuance
- examples
- textbook occurrences
- personal sentence examples
- clarifications
- reference material
- supplementary study links

This lets the same grammar concept connect textbook study, personal sentences and reference material.

---

## 10. Grammar references

The Hub combines several types of grammar support.

These may include:

- Dictionary of Japanese Grammar reference material
- NINJAL 文型 resources
- Grammar in Depth
- Multimedia Basic Grammar Workbook
- textbook occurrences
- personal examples

The canonical grammar guide is the central entry point.

The intended structure is:

**Textbook / sentence → canonical grammar guide → references and supplementary practice**

You normally do not need to search each reference source separately.

---

## 11. Supplementary grammar practice

Some grammar guides include optional supplementary resources.

Use these when:

- the textbook explanation was not enough
- you keep making the same mistake
- you want extra examples
- you want targeted practice after encountering the grammar

Supplementary material is not automatically part of the main programme workload.

It is there when needed.

---

## 12. Furigana

The Hub has a site-wide furigana control.

Use it according to the task.

A useful approach is:

- first read without furigana
- turn furigana on when blocked
- check the reading
- turn it off again if you want to test recall

There is no requirement to keep furigana permanently enabled or disabled.

---

## 13. Dark and light mode

The Hub supports dark and light appearance modes.

Use whichever is more comfortable.

The choice is persistent and does not affect study data.

---

## 14. Progress and completion

Progress reflects actual completed study work.

A task should normally be marked complete when the study activity itself is complete.

The Hub deliberately avoids unnecessary confidence or mastery ratings.

The useful records are:

- completed state
- notes
- study time
- programme progress

Completion should not be used to mean “I looked at this once.”

---

## 15. Programme states

Programmes can be:

- Planned
- Active
- Completed

Only one programme should be active at a time.

Changing the active programme changes which programme drives the main Plan.

Books are independent resources and do not need to become programmes automatically.

This distinction is intentional:

**Book ≠ Programme**

A book is a resource.

A programme is a structured commitment to study material over time.

---

## 16. WaniKani

WaniKani is treated as an external study resource rather than part of the core Learning Hub progression.

It can be accessed as a supporting tool, but the current Learning Hub programme does not depend on WaniKani progress.

---

## 17. Recommended daily workflow

For a normal study day:

1. Open **Home**
2. Go to **Plan**
3. Find today's or the next incomplete task
4. Open the relevant lesson
5. Start **Guided Lesson**
6. Work through the task
7. Use audio / shadowing where required
8. Use Pomodoro if useful
9. Mark completed work complete
10. Save useful personal sentences to the Repository when appropriate
11. Open grammar guides only when needed
12. Return to Plan when finished

The important part is that **Plan determines the next study action**.

---

## 18. Recommended weekly workflow

At the start of a study week:

1. Open Plan
2. Review the week's lesson workload
3. Check whether the schedule still fits your available time
4. Continue the active programme

At the end of the week:

1. Finish incomplete priority tasks
2. Review difficult grammar
3. Revisit useful saved sentences
4. Use supplementary practice only where there is a clear need
5. Continue to the next week

Avoid turning weekly review into a requirement to review everything.

---

## 19. What belongs where

| Need | Use |
|---|---|
| What should I study next? | Plan |
| Continue today's work | Guided Lesson |
| Browse a textbook | Hub → Book Library |
| Manage study programmes | Hub |
| Save a useful personal sentence | Repository |
| Understand grammar | Grammar Library |
| Find grammar reference material | Grammar guide |
| Extra grammar exercises | Supplementary resources |
| Focus timer | Pomodoro |
| Change programme calendar alignment | Plan footer |

---

## 20. What not to do

The Hub is most useful when it reduces friction.

Avoid:

- reorganising the Hub instead of studying
- creating new grammar guides for contractions or surface forms
- manually duplicating material already represented by a canonical guide
- turning every useful sentence into a large research project
- adding every resource you find to the programme
- treating supplementary material as mandatory
- changing programme structure every time a study session goes badly
- marking work complete simply to make progress numbers look better

A good maintenance rule is:

> Only change the Hub when actual study exposes a real problem.

---

## 21. If you do not know what to do next

Use this sequence:

**Plan → next incomplete task → lesson → Guided Lesson**

If you get stuck on Japanese:

**Sentence / lesson → grammar guide → reference or supplementary practice**

If you find useful Japanese outside the lesson:

**Repository → save sentence → link grammar**

That is the complete core workflow.
